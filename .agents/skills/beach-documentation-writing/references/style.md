# 文体と用語

## 日本語

- 1 段落 1 主張。主張を段落の最初の文に書く。
- 主語（誰が・何が計算するか）を明示し、能動の文にする。
- 用語は [`docs/Glossary.md`](../../../../docs/Glossary.md) の日本語を使う。識別子（設定キー、ファイル名、
  列名、コマンド）はコード書式で、言い換えずにそのまま書く。初出では「日本語（識別子）」とする。
- 英語の内部用語（closure、return、target、receipt、production、ownership、teacher など）を
  日本語の本文の説明語として使わない。用語集の訳を使う。
- 和文と英数字の間に半角スペースを入れる（句読点・括弧の隣を除く）。
- 「このページでは」「重要なのは」「次に〜を見る」のように、情報を足さない前置きを書かない。
- 「十分」「適切」「大きく」は、条件・値・比較に置き換える。
- 数値には単位を付ける。参照値は、条件（版、乱数 seed、thread 数）とあわせて書く。
- 注意書きを各段落に散らさない。適用範囲の節にまとめる。
- コマンド、設定、出力、ログはコードブロックに入れる。設定のコードブロックは ```toml。

## 英語版

- 日本語版と同じ見出し構成・同じ順序にする。内容の追加・省略をしない。
- 設定、コマンド、期待出力、警告、リンク先を日本語版と一致させる。
- アンカーは言語ごとに異なるので、ページ内リンクは英語の見出しから作る。

## 式

- インライン数式は `$...$`、別行立ては `$$` の行で囲む（サイト生成のテストが区切りを検査する）。
- 記号は初出で意味と単位を書く。同じ記号をページ内で別の意味に使わない。

## リンク

- ページ間は、日本語版では `Page.html`、英語版では `Page.en.html`（サイト生成時に変換される）。
  リポジトリ内のファイルは相対パス（`../examples/...`）。
- リンク文はリンク先のページ題か、そこで答えている問いにする（「こちら」にしない）。
