# 外部シースとの接続（Zhao 定常シース）

太陽風と紫外線にさらされた周期表面のセルで、上端面（z-high 面）の外にあるシースと整合した帯電を計算したいときに
読むページです。BEACH はセルの外に平面の定常シースを仮定してその零電流根を解き、根から上端面での 4 つの条件
（電流、電位基準、流入分布、流出障壁）を決めます。読み終えると、根が与える量と BEACH がそれをどう使うか、設定で何を
揃えるか、出力の何を見れば整合を確認できるかが分かります。

セルの高さは Debye 長（太陽風で約 10 m）よりはるかに小さいので、外部のシースから見ると上端面は表面そのものです。
シースを時間発展させるモデルではなく、既定では計算の開始時に根を一度だけ解きます。外部根の更新
（`sheath.coupling.outflow_refresh_batches`）を使うと、上端面を出ていく光電子の観測値から根を定期的に解き直します。
ケース全体の組み立て方は[プラズマ中の周期表面を設定する](PeriodicPlasmaSurface.html)にあります。

| 根が与えるもの | 上端面での使い方 | 節 |
|---|---|---|
| 粒子種ごとの電流 $J_e$、$J_i$、$J_{emit}$、$J_{return}$、$J_{escape}$ | 各バッチの吸収・放出・脱出の目標電荷 | [電流を根の値に固定する](#電流を根の値に固定する) |
| 壁電位 $\phi_0$ | 上端面の平均電位の基準（上流のプラズマを 0 V） | [上端面の電位を壁電位に合わせる](#上端面の電位を壁電位に合わせる) |
| 障壁 $\phi_m$（Type A）または 0 V | 入る粒子の選別と、出る粒子の反射・脱出の判定 | [上端面での粒子の出入り](#上端面での粒子の出入り) |
| 上流電子密度 $n_{e,\infty}$ | 上端面から入れる電子の密度 | [上流電子密度で電子を入れる](#上流電子密度で電子を入れる) |

## 何を解くか

上流（電位 0 V）の太陽風と、表面から放出される光電子がつくる 1 次元のシースです。表面への正味電流が 0 になる
定常解（零電流根）を求めます。

$$
J_e + J_i + J_{escape} = 0
$$

$J_e$ は電子の吸収電流、$J_i$ はイオンの吸収電流、$J_{escape}$ は外へ逃げる光電子の電流で、符号は表面帯電への寄与です。
光電子がない場合は $J_e + J_i = 0$ です。根は電位の形で 3 つの型に分かれます。光電子がなければ Type C だけです。

| 型 | 電位の形 |
|---|---|
| Type A | 表面と上流の間に電位極小 $\phi_m$ を持つ |
| Type B | 表面から上流へ単調に下がる（表面が正） |
| Type C | 表面から上流へ単調に上がる（表面が負） |

根からは、型（branch）、壁電位 $\phi_0$、電位極小 $\phi_m$、上流電子密度 $n_{e,\infty}$、粒子種ごとの電流が得られます。
BEACH は根を外部ライブラリ [sheath-model](https://github.com/Nkzono99/sheath-model) で解きます（`fpm.toml` で commit を固定）。
sheath-model は、代数的な根が次の条件を満たすかも検査し、満たさない根は採用しません。

- 電位分布の全域で $E^2\ge0$
- 上流で中性かつ電場 0 に近づく
- イオンの流れが途中で遮られない

`sheath.zhao.branch="auto"` は、太陽高度が 20 度未満なら C → A → B、それ以外は A → B → C の順に試し、成り立つ最初の根を返します。
`"a"`、`"b"`、`"c"` を書くとその型だけを解きます。成り立つ根がなければ、起動時に理由を表示して停止します。

## 仮定

- シースは平面、無衝突、非磁化、定常。
- 太陽風電子は、イオンと同じ太陽風の法線速度で drift した Maxwell 分布。上流へ戻る遅い電子は、入射分布の鏡像として反射する。
  この仮定は上流に接する幅数十 mV の帯で厳密には成り立たないので、帯の内側で欠ける場が太陽風の運動電場
  $\lvert\mathbf{u}\times\mathbf{B}\rvert$（約 2 mV/m）以下の根を受理する（[電子の drift と上流の帯](ZhaoUpstreamBand.html)）。
- イオンは上流で密度 $n_i$、法線速度 $u_i$、温度 $T_i$ を持ち、流束を保つ流体として輸送する（Sana & Mishra 2026）。
  圧力項の係数は `sheath.zhao.ion_pressure_factor`（1 は等温、3 は 1 次元断熱）で、入口は超音速 $m_i u_i^2/e > f\,T_i$ でなければ
  ならない。太陽風では入口エネルギー（400 km/s の陽子で約 0.86 keV）が $T_i$ よりはるかに大きく、$T_i\le12$ eV で根の変化は
  0.1 mV 以下である。根には BEACH が注入するイオンと同じ温度を使う。
- 光電子は表面から半 Maxwell 分布で放出され、その密度は $n_{pe,0}=s_{UV}\,n_{pe,ref}\sin\alpha$
  （$\alpha$ は太陽高度、$n_{pe,ref}$ は基準密度、$s_{UV}$ は倍率）。
- セルは外部シースから見て厚さ 0 の壁。

## BEACH での扱い

### 電流を根の値に固定する

役割を持つ 3 つの粒子種（電子、イオン、光電子）は、電荷の閉じ方を固定電流（`fixed_current`）にします。
各バッチで、追跡で得た分布を、根の電流にバッチ幅を掛けた目標電荷へ一律の倍率で合わせます。

| 経路 | 符号 | 扱い |
|---|---:|---|
| 電子の吸収 $J_e$ | 負 | 表面への吸収の目標 |
| イオンの吸収 $J_i$ | 正 | 表面への吸収の目標 |
| 光電子の放出 $J_{emit}$ | 正 | 放出元に残す反作用電荷の目標 |
| 光電子の帰還 $J_{return}$ | 0 以下 | 表面への再吸収の目標 |
| 光電子の脱出 $J_{escape}$ | 正 | 表面に置かない、外部へ出る電流 |

根は $J_{return}=J_{escape}-J_{emit}$ と $J_e+J_i+J_{escape}=0$ を満たすので、表面の電流は
$J_e+J_i+J_{return}+J_{emit}=0$ で閉じます。放出と帰還は別々の倍率で合わせ、二つの大きな電流の差である
光電子の正味電流を倍率の分母に使いません。このため表面の総電荷は浮遊条件に拘束され、要素ごとの分布だけが追跡で決まります。

### 上端面の電位を壁電位に合わせる

上端面の水平平均電位を壁電位 $\phi_0$ に合わせます。真空中で定数を足すだけなので、セル内の電位差と粒子の軌道は変わらず、
電位の値が上流のプラズマ 0 V を基準にした値になります。流入の写像と外部障壁の判定はこの電位を前提にするので、
場の面平均成分を分けて扱う周期セル（`fields.boundary="periodic2"`、x/y 周期、`fields.periodic.backend` が `cached_kneq0`
または `panel_spectral_reference`）が必須です。面平均成分を分けない設定は設定エラーになります。

面平均成分を分けないと上端面の電位は約 0 V のままになり、流入する電子は減速されず、光電子は浅すぎる障壁で判定されます。
平板 8×8・20 バッチで比べると、分ける設定では平面の平均電位が根の $\phi_0$（Type A で 2.654 V、Type C で −9.422 V）と
0.1 mV 以内で一致し、固定電流の倍率は全チャネルで統計誤差の範囲で 1 でした。分けない設定では平面の平均電位が 0 V 付近に留まり、
電子の倍率は 0.53（Type C）、光電子の帰還と escape の倍率は 1.99 と 0.30（Type A）にずれました。

### 上端面での粒子の出入り

**流入:** 太陽風は上流 0 V の分布から、外部シースの障壁と上端面の両方に届く部分だけを選び、法線速度を
エネルギー保存で上端面へ写します。

$$
\frac12 m v_{n,f}^{2}=\frac12 m v_{n,\infty}^{2}-q\phi_f
$$

$\phi_f$ はバッチ開始時の上端面の平均電位、$v_{n,\infty}$ は上流での法線速度です。

**流出:** 上端面を外向きに横切った電子と光電子は、横切った点の電位 $\phi_c$ と法線方向の運動エネルギーで、
外部の障壁を越えられるかを判定します。越えられないものは法線速度を反転して戻し、越えられるものは脱出とします。

| 型 | 電子が入るときの障壁 | 電子・光電子が出るときの障壁 | イオン |
|---|---:|---:|---:|
| Type A | $\phi_m$ | $\phi_m$ | 0 V |
| Type B / C | 0 V | 0 V | 0 V |

例えば Type A で $\phi_0\approx6.9$ V、$\phi_m\approx-0.07$ V なら、上端面から出る電子は法線エネルギーが約 7 eV 未満だと戻されます。
Type C では壁が負なので、外へ向かう電子はすべて脱出します。

x/y 周期のセルでは、戻す位置を上端面内で一様に選び直します。外部シースの中で粒子が横に動く距離は、
飛行時間と接線速度の積で m 程度になり、セル幅よりはるかに大きいためです。戻す位置の電位 $\phi_r$ で
法線方向の運動エネルギーを合わせ、全エネルギーを保ちます。

$$
\frac12 m v_{n,r}^{2}=\frac12 m v_{n,c}^{2}+q(\phi_c-\phi_r)
$$

右辺が 0 以下になる遅い粒子は、外部での滞空が短く横へほとんど動かないので、横切った位置へ戻します。
接線速度は変えません。

### 上流電子密度で電子を入れる

壁に届いた電子は吸収されて戻らないので、上流の電子分布は外向きの高速成分が欠けています。根は、この欠けを含めて
上流で準中性になるよう、電子 Maxwell 分布の密度 $n_{e,\infty}$ を解きます。光電子なしの Type C では

$$
n_{e,\infty}=\frac{n_i}{1-\frac12\operatorname{erfc}\sqrt{-\phi_0/T_e}}
$$

で、イオン密度 $n_i$ より大きくなります。BEACH は上端面からの電子をこの $n_{e,\infty}$ で、イオンを設定の $n_i$ で入れます。
これで入れた電子の束が根の電子電流と一致し、電子の倍率は統計誤差の範囲で 1 になります。
外部根を更新するたびに $n_{e,\infty}$ も更新します。

### 外部根を更新する

セル内の凹凸は、外部シースから見た表面の放出を変えます。表面から出た光電子の一部はセル内で再吸収されるので、
上端面を出る光電子は放出より少なく、エネルギー分布も変わります。外部根の更新は、この変化を外部シースへ返します。
受理したバッチが `outflow_refresh_batches` 個たまるごとに、次を行います。

1. 上端面を外向きに横切った光電子を、法線運動エネルギー $K$ の bin ごとに数える。表面からの放出数 $N_{emit}$ も合計し、
   透過率 $\eta=N_{out}/N_{emit}$ を求める（$N_{out}$ は全 bin の合計）。
2. 外部シースの光電子源を、数えたスペクトルに置き換えて零電流根を解く。各 bin の束は全体が $\eta\Gamma_{emit}$ になるように
   比例配分し、bin の中では $d\Gamma/dK$ を一定とする。$\Gamma_{emit}$ は設定から決まる表面の放出束で、表面の放出の目標は変えない。
3. 新しい根の電流・障壁・壁電位・上流電子密度を、次のバッチから使う。

bin は $[0, 1\,\text{meV})$ と、1 meV から 1 keV までの対数 bin（1 桁に 24 個）で、1 keV 以上は最後の bin に数えます。
スペクトルを平均エネルギーだけの半 Maxwell 分布へ縮約しないのは、上端面のスペクトルが、放出に近い低エネルギーの本体と、
セル内の電位差で加速された高エネルギーの裾を合わせた形になりうるためです。平均は裾で決まるので、同じ平均の半 Maxwell
分布は、障壁を越えて逃げる電子と壁の近くの遅い電子の両方を誤って数え、根を失うことがあります。

| 状況 | 動作 |
|---|---|
| `sheath.zhao.branch` を明示 | その型だけを解く |
| `sheath.zhao.branch="auto"` | 直前の型を先に試し、解けなければ A → B → C の順に探す（太陽高度による並べ替えは初期根だけ）。前回の根を初期値に使う |
| 根が見つからない、または流出が 0 | 警告し、直前の根を保つ |
| 再開 | 保存した光電子源（スペクトル）から根を作り直す。途中まで合計した分は捨て、再開時点から数え直す |

更新のたびに使う光電子の標本が少ないと、根は統計雑音で揺れます。設定例（光線 300 本/バッチ、更新間隔 2 バッチ、
平板）では、更新ごとの $\phi_0$ が 2.34〜2.94 V の範囲で揺れ、標準偏差は 0.17 V でした。発散や型の切り替わりはなく、
揺れは窓内の標本数で決まるので、`outflow_refresh_batches` を長くするか光線数を増やして抑えます。間隔は、表面の
帯電の変化より十分短く選びます。定常状態だけが目的なら、到達する状態は間隔によりません。

## 設定

```toml
[sheath]
closure = "zero_current"

[sheath.zhao]
branch = "auto"
upstream_field_floor_v_m = 0.002

[sheath.species]
electron = "solar_wind_electron"
ion = "solar_wind_ion"
photoelectron = "photoelectron"

[sheath.photoelectrons]
solar_elevation_deg = 60.0
ref_density_m3 = 6.4e7

[sheath.coupling]
outflow_refresh_batches = 50
```

- 役割を持つ粒子種は `charging.closure="fixed_current"`。電子とイオンは上端面から境界流入、光電子は上端面からの
  `photo_raycast` で反作用電荷あり。上端面は開放。
- 電子とイオンの数密度には同じ太陽風密度を書く（違えば設定エラー）。電子とイオンの drift は、どちらも太陽風の法線速度
  （負の z）にする。電子の drift を 0 にするなら `upstream_field_floor_v_m` は不要だが、$\phi_0$ が約 1 V ずれる
  （[電子の drift と上流の帯](ZhaoUpstreamBand.html)）。
- イオンの温度は粒子種の `temperature_ev` から外部根にも渡る。`sheath.zhao.ion_pressure_factor` は圧力係数を変えるときだけ書く。
- 光電子なし（Type C）は `sheath.photoelectrons.source_scale=0.0` とし、光電子の粒子種と関連キーを省く。
  外部根の更新は使えない。
- 光電子の `emit_current_density_a_m2` はレイ垂直面基準なので、表面の放出はそれに ray 仰角の sin を掛けた値になる。
  外部源 $e\,s_{UV}\,n_{pe,ref}\sin\alpha\,v_{th}/(2\sqrt\pi)$ と一致させるには、`emit_current_density_a_m2` を垂直入射の値
  $e\,s_{UV}\,n_{pe,ref}\,v_{th}/(2\sqrt\pi)$（設定例では 2.54 µA/m²）にし、`ray_direction` の仰角を `solar_elevation_deg` に
  合わせる。5% 以上ずれると起動時に警告する。固定電流の放出倍率が差を吸収するので収支は閉じるが、放出の生の粒子数が
  目標から離れた状態で統計が組まれる。

全キーと組み合わせの制約は[入力パラメータ](Parameters.html#surface_current_model-外部シースclosure)にあります。完全な例は
[`examples/zero_current.toml`](../examples/zero_current.toml)、
[`zero_current_refresh.toml`](../examples/zero_current_refresh.toml)、
[`zero_current_no_photo.toml`](../examples/zero_current_no_photo.toml) です。

| `charge_ledger.csv` | 粒子種ごとの追跡・目標・適用の電荷、`fixed_*_weight_scale`、個数 |

| `matching_plane_spectrum_history.csv`（外部根の更新） | 外部根を更新した batch ごとの外部源スペクトル。セル内で加速された裾の割合 |
| `top_reference_history.csv` | `potential_mean_V` が $\phi_0$ に一致すること。ずれは場の誤差で、障壁の判定をずらす（[遠方補正の精度](PeriodicFarCorrection.html)） |

倍率が粒子種によって大きく違うと、要素ごとの電流の釣り合いが追跡だけで決まる状態からずれます。
列の定義は[出力形式](OutputReference.html#zhao_stationary)にあります。

零電流の残差が小さくても、追跡で得た吸収・帰還の空間分布が収束したことにはなりません。光線数、バッチ幅、
乱数 seed を変えて、要素ごとの分布が変わらないことを確かめます。

## 適用範囲

- box の外の電場、空間電荷、Debye 遮蔽、折り返し点までの距離や飛行時間は解きません。上端面での反射は、
  外部での往復を境界での反転に縮めた近似です。
- 一様磁場は 0 でなければなりません。
- 平面の定常解なので、曲率、衝突、外部シースの過渡、計算中に変わる照射やプラズマ条件には追従しません。
  外部根の更新が追従するのも、上端面を出る光電子の変化だけです。

### 既知の制約

- **上流の帯:** 電子に drift を与えた A/C の根は、上流に接する幅数十 mV の帯の内側で理想化した電子分布に従いません。
  壁の量への影響は数十 mV です（[電子の drift と上流の帯](ZhaoUpstreamBand.html)）。
- **光電子源の離散化:** 外部根の更新では、上端面を出る光電子を法線運動エネルギーの bin だけで表し、bin の中の分布は一定とします。
  接線方向の速度と、表面上の位置による違いは外部シースに渡しません。初期根（最初の更新まで）は表面放出の半 Maxwell 分布で解きます。
- **跳ね返された太陽風粒子を戻さない:** セル内で跳ね返されて上端面から出ていく太陽風の電子とイオンは、外部根に入れていません。
  外部根は壁に届いた電子とイオンをすべて吸収とみなします。固定電流はこの分も吸収として表面に配るので、総電流の釣り合いは
  保たれます。逃げる割合は `fixed_current_history.csv` の電子とイオンの倍率の 1 からのずれで読めます。光電子のない Type C では、
  電子が届きにくくイオンだけが当たる面が、イオンの運動エネルギー（400 km/s の陽子で約 0.84 kV）近くまで正に帯電し、
