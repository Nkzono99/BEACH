# 電子の drift と上流の帯

太陽風の電子にイオンと同じ drift を与えると、外部シースの Type A / C の根が既定では棄却されます。このページは、
その理由と、`sheath.zhao.upstream_field_floor_v_m` に何を書けばよいかを説明します。推奨は太陽風の運動電場
$\lvert\mathbf{u}\times\mathbf{B}\rvert$ の目安 2 mV/m（400 km/s、5 nT）です。読み終えると、受理した根がどの範囲で近似であり、
壁側の量にどれだけ影響するかが分かります。外部シースのモデル全体は[外部シースとの接続](ZhaoStationaryClosure.md)にあります。

## 帯が生じる理由

上流で表面へ向かう電子の分布を、表面系の内向き法線速度 $a$ で $g(a)$ と書きます。遅い電子（Type A では $\phi_m$、Type C では
壁に届かないもの）は電位に反射され、同じ速さで上流へ戻ります。この鏡像反射と Liouville の定理から、上流電位 $0$ から深さ
$h=-\phi/T_e$ だけ下がった点の電子密度は

$$
n_e(h)-n_e(0)=\int_0^\infty\bigl[g(\sqrt{w^2+h})-g(w)\bigr]\,dw
\approx g(0)\,O(h)+g'(0)\,\tfrac{h}{2}\log\tfrac{1}{h}
$$

になります。係数 $g'(0)$ は、表面系で速度 0 の電子に対する入射分布の傾きです。drift のない Maxwell 分布は $g'(0)=0$ で
この項は現れませんが、drift $u$ のある分布は $g'(0)=2u\,g(0)>0$ なので、上流に近づくほど電子の過剰が
$h\log(1/h)$ で現れます。イオンと光電子の密度は $\phi$ について正則（$O(h)$）なので、この項を打ち消せません。
イオンの温度を入れても同じです。

帯が生じるには、次の 3 つの仮定が同時に成り立つ必要があります。

1. 表面系で $g'(0)\ne0$（drift のある入射分布）
2. 遅い電子が定常な 1 次元電位で完全に鏡像反射される
3. 上流の無限遠で厳密に中性・電場 0 に接続する

## 電位分布はどうなるか

sheath-model は電位分布を $z$ で積分するのではなく、Poisson 方程式の第一積分 $E^2(\phi)=(2/\varepsilon_0)\int_0^\phi\rho\,d\phi'$
を $\phi$ の関数として扱います。根を決める条件（上流 0 V での準中性、零電流、Type A の接続条件 $E^2(0)=0$）はすべて
$\phi$ 空間の積分条件なので、途中で $E^2$ が負になっても解けます。

受理した根では、$E^2(\phi)$ は上流の手前 $\phi_b$（Type A の設定例で約 −42 mV）でゼロを切って負になり、$\phi=0$ でゼロに
戻ります。$E^2<0$ の区間には実数の $z(\phi)$ がないので、電位分布は $\phi_b$ で傾き 0 の極大になって止まります。
$\phi_b$ は上端面から $3\lambda_D$（約 30 m）程度の有限の距離にあり、壁側 $z<z_b$ の分布は普通に構成できます。
sheath-model のプロファイル生成も帯の手前で打ち切ります。BEACH が使う量（$\phi_0$、$\phi_m$、$n_{e,\infty}$、各電流、障壁）は
積分条件の代数根から決まるので、帯の存在そのものには影響されません。

帯の内側で欠けている場 $\sqrt{-\min E^2}$ は、1 次元静電シースが上流へつながるために外から供給されなければならない電場です。
これが次の受理基準の量になります。

## 受理の基準

| キー | 既定 | 受理する根 |
|---|---:|---|
| `sheath.zhao.upstream_field_floor_v_m` | 0 | 帯の内側の場の不足 $\sqrt{-\min E^2}$ がこの値 [V/m] 以下 |
| `sheath.zhao.upstream_band_tolerance` | 0 | 帯の電位幅が、A では $\lvert\phi_m\rvert$、C では $\lvert\phi_0\rvert$ のこの割合以下 |

両方を書けば両方を満たす根だけを受理し、両方 0 なら drift のある A/C を棄却します。どちらの基準でも受理する根は
同じ代数根なので、壁側の量は基準の選び方によりません。

**場の下限（推奨）。** 上流境界を「$E=0$ の無限遠」から「場が外部レベルまで落ちた点」に置き換える判定です。太陽風は
運動電場 $\lvert\mathbf{u}\times\mathbf{B}\rvert$（400 km/s、5 nT で約 2 mV/m）を持ち、磁場や密度揺らぎもこの桁の場で効くので、
1 次元静電シースにこれ以下の場を決める資格はありません。実測した不足は次のとおりで、どれも運動電場より小さいです。

| 条件 | 型 | 帯の幅 | 場の不足 |
|---|---|---:|---:|
| 設定例（$n=8.7$ cm⁻³、$T_e=12$ eV、405 km/s、太陽高度 60 度、光電子あり） | A | 42 mV | 0.63 mV/m |
| 同、光電子なし | C | 1.8 mV | 0.03 mV/m |
| $n=5$ cm⁻³、$T_e=10$ eV、400 km/s、光電子 4.5 µA/m²・2.2 eV | A | 52 mV | 0.67 mV/m |

**幅の許容。** 同じ帯を電位幅で判定します。上の条件では A の帯は $\lvert\phi_m\rvert$ の 4〜7%、C は 0.04% です。

**電子の drift を 0 にする。** 帯は消えますが、電子の束が $e^{-u^2}+\sqrt\pi\,u\,(1+\operatorname{erf}u)$ 倍（$u=0.21$ で 1.42 倍）
変わり、零電流の根ではその差が電位に現れます。上の 3 行目の条件で、drift 0 の根は A で $\phi_0$ が 6.04 → 7.05 V、C で
−7.34 → −4.63 V でした。三層の粒子層では、セル内の電位が全体に A で約 1 V、C で 3〜4 V 上がり、層の間の電位差の変化は
1% 以下でした。帯を受理したときの不確かさ（数十 mV）よりずっと大きいので、BEACH は帯を受理する方法で drift を扱います。

## 現実のプラズマで帯を埋めるもの

帯が問題にするのは、表面系で $\lvert v_z\rvert\lesssim0.07\,v_{th}$（約 150 km/s）、エネルギー 1 eV 以下の電子です。
1 次元静電モデルが落としている物理が、この集団に対しては支配的になります。

| 量（$n=8.7$ cm⁻³、$T_e=12$ eV、$B=5$ nT） | 値 |
|---|---:|
| Debye 長 $\lambda_D$ | 約 9 m |
| 帯の領域（$\lvert\phi\rvert<50$ mV、$3$〜$7\lambda_D$） | 30〜60 m |
| 電子サイクロトロン周期 | 7 ms |
| 遅い電子が帯の領域を通る時間 $\tau$ | 0.2〜0.4 ms |
| 通過中の旋回角 $\Omega\tau$ | 0.2〜0.35 rad |

- **磁場による旋回混合。** 熱的な電子は帯を 20〜30 µs で通るので非磁化近似が成り立ちますが、遅い電子は通過中に
  0.2〜0.35 rad 旋回し、磁場が法線に垂直な成分を持てば $v_\perp\approx v_{th}$ の一部が $v_z$ に回って 400〜700 km/s 変わります。
  尖りの幅（150 km/s）を超えるので、$v_z\approx0$ の分布は滑らかになります。
- **太陽風の揺らぎ。** 密度揺らぎ数〜10% は電位の揺らぎ $T_e\,\delta n/n\approx0.1$〜$1$ V に相当し、帯の幅 50 mV はその下に
  埋まります。定常な $E\to0$ の接続は実現しません。
- **運動論的不安定性。** 速度 0 で尖った分布は Penrose 条件を破り、準線形拡散で平坦化します。遅い電子の滞在時間はプラズマ
  周期（38 µs）の 5〜10 倍です。
- **有限の天体と対流。** 磁力線が昼側表面に接続している時間は $R_{\rm Moon}/u\approx4$ s で、反射電子は磁力線に沿って流され、
  半無限 1 次元の定常な鏡像集団は溜まりません。

どの機構が主かは直接には確かめられていません。対象の集団は宇宙機電位（数 V）に埋もれ、観測されていないためです。
場の下限 $E_{floor}\approx\lvert\mathbf{u}\times\mathbf{B}\rvert$ は、これらの外側の物理が効き始める場の大きさとして読みます。

## 適用範囲

- 受理した根は、帯の内側では理想化した電子分布に従いません。遅い入射電子（$a\lesssim a_s$）の drift だけを除いて滑らかにした
  軌道整合の解と比べると、壁電位の差は $a_s=0.07$〜$0.2$ で 20〜80 mV、電子の吸収束の差は 0.3% 未満でした
  （[検証記録](https://github.com/Nkzono99/sheath-model/blob/main/outputs/upstream_relaxation_20261009/REPORT.md)）。
  壁側の量の不確かさはこの数十 mV です。
- 場の下限は帯を埋める物理を解くものではなく、1 次元静電モデルの外側に責任を渡す境界条件です。磁場の向きや
  揺らぎの大きさが太陽風の典型値から外れる条件では、$E_{floor}$ をその条件の外部の場に合わせます。
- イオンの温度（流体モデル）は帯を変えません（$T_i\le12$ eV で帯の幅と場の不足の変化は 1% 未満）。
