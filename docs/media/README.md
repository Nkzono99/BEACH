# 概念図の作成規則

`concepts/` の図は縮尺なしの模式図です。物理モデルや数値手法の説明に隣接して置き、数値解・実測結果と区別します。

- 電子・負電荷は青 `#2563b0` と `−`、正イオン・正電荷は赤 `#c44343` と `+` で示します。
- メッシュ・計算処理は青緑 `#087f83`、場・補助線は灰 `#64748b`、光線は黄土 `#a66a08` を使います。
  色だけで区別せず、符号・ラベル・矢印を添えます。破線の意味は各図で説明します。
- 白い角丸カードに濃色の文字を置き、暗いページでも線と文字のコントラストを保ちます。
- SVG を編集可能な正本とし、日本語は実テキストで残します。フォントは system-ui、Noto Sans CJK JP、
  ヒラギノ角ゴ、Meiryo などのシステム sans-serif を使い、外部フォントを読み込みません。
- 基本幅は 960、本文は 20〜24、題は 28 の SVG 座標単位を目安にします。`viewBox` を付け、文字を輪郭化しません。
- 各 SVG に `title` と `desc`、ページには内容を述べる日本語の代替テキストと1文の説明を付けます。
- 矢印の向き、電荷の符号、境界の周期軸、処理の順序を本文と Fortran 実装で確認します。
  物理量の関係だけを描く曲線には、模式図であることを明記します。
- ページからは `../media/concepts/名前.svg`（入口では `media/concepts/名前.svg`）で参照します。
  サイト同期は `media/` を再帰コピーし、画像パスを `/BEACH/media/…` へ変換します。

既存の `tutorial_*` は定量的なチュートリアル図、`fortran_module_dependencies.svg` は自動生成物です。
この規則を適用するためだけに、それらを書き換えません。
