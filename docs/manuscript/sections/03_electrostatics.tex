\chapter{三角形境界要素による静電場}
\label{ch:electrostatics}

\section{P0 表面電荷の積分}
自由空間の Coulomb 定数を $\kc=(4\pi\eps)^{-1}$ とすると、
式\eqref{eq:p0}の source が作る電位と電場は
\begin{align}
 \phi(\vect x)&=\kc\sum_{i=1}^{N}\frac{q_i}{A_i}
       \int_{T_i}\frac{1}{\lVert\vect x-\vect y\rVert}\dd S_{\vect y},
       \label{eq:panel_phi}\\
 \vect E_{\mathrm s}(\vect x)&=\kc\sum_{i=1}^{N}\frac{q_i}{A_i}
       \int_{T_i}\frac{\vect x-\vect y}
       {\lVert\vect x-\vect y\rVert^3}\dd S_{\vect y}.
       \label{eq:panel_field}
\end{align}
要素電荷は粒子の吸収・放出から蓄積量として決まるため、絶縁体では、
境界電位から全 $q_i$ を逆算する連立方程式は解かない。
浮遊導体の等電位化（第\ref{ch:update}章）だけが、追加の境界条件を連立方程式として課す。

P0 は要素ごとの一定密度近似であり、真の表面電荷密度の連続性や細部を完全には表さない。
面の積分を正確に評価しても、三角形形状と密度の離散化誤差は残る。

\section{辺の対数項と立体角}
一つの三角形について解析積分の構造を示す\citep{Wilton1984}。評価点 $\vect x$ の面からの符号付き高さを
$d=(\vect x-\vect a_1)\cdot\vect n$、平面への投影を $\vect x_\parallel$、辺 $e$ の面内外向き単位法線を $\vect\nu_e$、
辺 $e$ 上の一点を $\vect a_e$ とする。辺の長さを $\ell_e$、評価点から両端までの距離を $r_{e,1},r_{e,2}$ とおくと、
\begin{equation}
 L_e=\log\frac{r_{e,1}+r_{e,2}+\ell_e}
                   {r_{e,1}+r_{e,2}-\ell_e},\qquad
 d_e=(\vect a_e-\vect x_\parallel)\cdot\vect\nu_e
\end{equation}
を用いて
\begin{align}
 I_\phi&=\sum_e d_eL_e-d\,\Omega,\\
 \vect I_E&=\sum_e\vect\nu_eL_e+\vect n\Omega,\\
 \phi_i&=\kc\frac{q_i}{A_i}I_\phi,\qquad
 \vect E_i=\kc\frac{q_i}{A_i}\vect I_E
\end{align}
となる。$\Omega$ は評価点が法線 $\vect n$ の側にあるとき正となる符号付き立体角であり、
頂点への相対ベクトル $\vect r_k=\vect a_k-\vect x$（$r_k=\lVert\vect r_k\rVert$）から
\begin{equation}
 \Omega=-2\operatorname{atan2}\Bigl(\vect r_1\cdot(\vect r_2\times\vect r_3),\;
 r_1r_2r_3+(\vect r_1\cdot\vect r_2)r_3+(\vect r_2\cdot\vect r_3)r_1+(\vect r_3\cdot\vect r_1)r_2\Bigr)
\end{equation}
で計算する\citep{VanOosterom1983}。
評価点が面上にあるときは、次節の自己項と片側極限を用いる。

重心に点電荷を置く近似と異なり、三角形の広がりを近傍でも保持する。
特異性を経験的な softening 長で置き換えることはしない。

\section{自己電位と片側電場}
要素内の評価点では、面上の電位は連続であり、面積を持つ三角形の自己電位も有限である。
法線電場は表面電荷によって跳ぶ。
\begin{equation}
 \vect E_i^{\pm}
 =\vect E_i^{\mathrm{PV}}\pm\frac{\sigma_i}{2\eps}\vect n_i,
 \qquad
 \vect n_i\cdot(\vect E_i^+-\vect E_i^-)=\frac{\sigma_i}{\eps}.
 \label{eq:jump}
\end{equation}
$\mathrm{PV}$ は両側極限の平均としての principal value である。
面上の電場には、粒子が存在する側の片側極限を用いる。閉じた物体では外向き法線の側をとる。
衝突は面の両側から検出する（第\ref{ch:particles}章）ので、衝突の表裏と電場の片側極限の選択は独立である。
